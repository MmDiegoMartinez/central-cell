Cancelación de Venta PayJoy

list_alt 9 pasos + caso especial groups Vendedores y encargados

Sigue este proceso cuando sea necesario cancelar una venta PayJoy, asegurando que la documentación del cliente esté completa y autorizada antes de devolver el enganche y retirar la aplicación del equipo.

flag

Objetivo

Establecer el proceso correcto para realizar una cancelación de venta PayJoy de forma rápida, clara y ordenada, asegurando que la documentación del cliente esté completa y autorizada antes de devolver el enganche y retirar la aplicación del equipo.

rule

Restricciones

Para poder realizar una cancelación, se debe cumplir con lo siguiente:

  • La venta debe tener máximo 5 días de haberse realizado
  • El equipo debe estar en buenas condiciones y funcionando correctamente
  • El formato de cancelación debe estar correctamente llenado y firmado
groups

Alcance

Este proceso aplica para:

  • Apasionado de telefonía
  • Encargados de sucursal

Proceso de Cancelación

Sigue estos pasos en orden para completar correctamente la cancelación de la venta.

description

📄 Formato de cancelación

Descarga aquí el formato oficial que el cliente y el vendedor deben llenar y firmar.

download Descargar Orden de Cancelación (PDF)

1

Descargar el formato

Descarga el formato de cancelación desde el enlace de esta página.

2

Llenar el formato

Una vez descargado, el formato debe ser llenado completamente a puño y letra por el cliente.

3

Firma del cliente

El cliente debe colocar su firma en el formato.

4

Firma del vendedor

El vendedor también debe firmar el formato.

info

Importante: la firma del vendedor debe coincidir con la registrada en el perfil de su cuenta PayJoy.

5

Enviar el formato

Cuando el formato esté completo, envía una fotografía clara del documento al medio de envío asignado.

6

Adjuntar la INE del cliente

Adjunta también fotografías claras de la INE del cliente:

  • Frente
  • Reverso
7

Esperar autorización

Espera la validación y autorización por parte del auxiliar o jefe del departamento.

warning

⚠️ No continúes sin confirmación

No se debe continuar el proceso hasta recibir confirmación.

8

Devolver el enganche

Una vez autorizada la cancelación, devuelve el enganche al cliente.

9

Retirar la aplicación

Finalmente, retira o desinstala la aplicación PayJoy del equipo.

Cancelación de pagos

También es posible cancelar pagos de PayJoy

receipt_long

📌 ¿En qué consiste?

Para cancelar un pago, la solicitud debe realizarse el mismo día en que se efectuó la transacción. Es necesario enviar al departamento correspondiente el recibo de pago de la venta que se desea cancelar, ya que este contiene todos los datos necesarios del cliente.

verified_user

Una excepción, no la regla

Esta forma de cancelar está pensada solo para casos realmente justificados —una situación mayor que amerita revertir la venta de inmediato— y no para cambios de opinión o detalles menores que se pueden resolver de otra forma. Úsala con criterio y siempre informando al departamento correspondiente.
